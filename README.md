# 群统计报表（astrbot_plugin_group_stats）

AstrBot 群活跃度统计与日报/周报插件：自动统计每个群每位成员的每日发言情况，支持发言排行、热词话题、活跃时段、成就勋章、积分制活跃榜查询，并可定时向指定群推送每日统计摘要。

- **作者**：云晓
- **版本**：1.0.0
- **许可证**：MIT（详见 [LICENSE](LICENSE)）

## 功能

### 消息统计
- 监听群消息，按群、按成员、按日期记录发言数据
- 统计量：发言条数、字符总数、图片数
- 只统计普通文本消息（命令消息不计入），始终忽略机器人自身
- 可配置是否忽略其他机器人账号的发言（`stats_ignore_bots`，默认开启）
- 数据存于内存，每 5 分钟定期落盘，插件卸载时强制落盘

### 排行查询（`/群统计`）
- `/群统计`：今日群聊简版总览（总发言条数 / 参与人数 / 最活跃成员）
- `/群统计 今日`：今日发言排行 Top10（昵称 + 条数）
- `/群统计 本周`：本周（周一至今）发言排行 Top10
- `/群统计 我的`：我的今日发言统计（条数 / 字符 / 图片）
- `/群统计 帮助`：查看全部用法
- 命令兼容 `/`、`／` 全角斜杠与无斜杠前缀

### 热词话题统计
- `/群统计 热词`：今日热词话题 Top10
- `/群统计 热词 本周`：本周热词话题 Top10
- 内置中文分词：正则提取连续中文片段，滑动窗口取 2-6 字词组，内置停用词表过滤虚词/口语词

### 活跃时段分析
- `/群统计 时段`：今日各小时发言分布（条形图 + 占比 + 最活跃时段）
- `/群统计 时段 本周`：本周活跃时段分布
- 按小时（0-23 时）统计，无发言的小时不展示，避免刷屏

### 成就勋章系统
- `/群统计 勋章`：我的勋章墙（已获得 + 可获得的勋章一览）
- `/群统计 勋章 <用户ID>`：查看他人勋章墙
- 勋章不重复颁发、永久保留；周冠军勋章由每日日报任务自动结算（同一周内只颁发一次）

| 勋章 | 获得条件 |
| --- | --- |
| 坚持之星 | 连续 7 天发言 |
| 话痨王 | 单日发言 ≥ 50 条 |
| 早起鸟 | 6-8 点发言 |
| 夜猫子 | 0-3 点发言 |
| 图霸 | 单日图片 ≥ 10 张 |
| 周冠军 | 本周发言榜第一 |
| 水群大师 | 累计发言 ≥ 500 条 |

### 积分制活跃榜
- `/群统计 积分`：今日积分榜 Top10
- `/群统计 积分 本周`：本周积分榜 Top10
- `/群统计 积分 本月`：本月积分榜 Top10
- `/群统计 积分 我的`：我的今日积分（含每日上限提示）
- 积分规则：普通发言 +1 分；带富媒体（图片/语音/视频）的消息每条再 +2 分；被 @ 一次 +3 分；每人每日积分上限 200 分

### 自动日报
- 配置 `stats_report_enable` 开启后，后台每 30 秒检查一次，到达 `stats_report_time`（默认 22:00）时向 `stats_report_groups` 指定的群推送当日统计摘要
- 日报内容：总发言 / 参与人数 / 总字符 / 图片数、活跃 Top5、热词 Top5、活跃时段条形图、积分 Top5
- 同日同群去重，已推送日期持久化，重启不重复推送；当日无发言数据的群不推送
- 日报目标群平台可通过 `stats_report_platform` 指定；留空时插件自动学习（目标群有消息后自动生效）

### 数据清理
- `stats_keep_days`（默认 30 天）控制统计保留天数，自动清理过期数据（热词/时段/积分同步清理；成就勋章永久保留）

## 配置

见 `_conf_schema.json`，关键项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `stats_report_enable` | bool | `false` | 是否启用每日自动群日报推送 |
| `stats_report_time` | string | `22:00` | 每日日报推送时间（HH:MM） |
| `stats_report_groups` | string | 空 | 自动日报推送的目标群号列表，逗号分隔 |
| `stats_report_platform` | string | 空 | 日报目标群所属平台实例 ID；留空自动学习 |
| `stats_keep_days` | int | `30` | 统计数据保留天数，自动清理过期数据 |
| `stats_ignore_bots` | bool | `true` | 是否忽略机器人账号的发言统计 |

## 数据存储

存储于 `plugin_data/astrbot_plugin_group_stats/`：

- `stats.json`：按群按日期按成员的发言统计数据
- `report_dates.json`：日报推送去重记录（群号 → 已推送日期）
- `extras.json`：热词话题词频与活跃时段分布
- `achievements.json`：成就勋章记录（含获得日期）
- `points.json`：按日积分记录

全部文件采用 tmp + os.replace 原子写，避免写一半损坏；加载时带结构校验与脏数据防御，损坏数据静默重置。
